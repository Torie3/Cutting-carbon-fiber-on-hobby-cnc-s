# Carbon Fiber FPV Drone Frame for the Genmitsu 3030 Prover Ultra

This repository contains all files required to manufacture and assemble my custom carbon fiber drone frame using a Genmitsu 3030 Prover Ultra CNC.

## Repository Contents

### CAD Files
- Frame design files
- Source CAD models
- Exported manufacturing geometry

### CAM Files
- Toolpaths
- Fusion 360 manufacturing setup files
- Post-processed G-code where applicable

### Tool Library
- Carbon fiber tooling definitions
- Feeds and speeds
- Tool presets used during testing

### Documentation
- Manufacturing notes
- Assembly information
- Material recommendations
- Machining guidelines

## Design Goals

This frame was designed with the following objectives:

- Lightweight construction
- High stiffness
- Good crash resistance
- Easy manufacturing on hobby CNC equipment
- Compatibility with commonly available FPV components

## Manufacturing

The frame was primarily designed to be machined from carbon fiber sheet material on a Genmitsu 3030 Prover Ultra CNC.

Recommended tooling and machining parameters are included in the tool library provided in this repository.

A detailed machining guide is available in:

`How to Cut Carbon Fiber on the 3030 Prover Ultra.pdf`
